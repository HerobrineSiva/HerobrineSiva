## 📚 My Personal Initiative — ToPeWe

**ToPeWe** means **Topic Per Week**:

- **To** = Topic
- **Pe** = Per
- **We** = Week

Each week, I aim to choose one topic, research it, learn its fundamentals, try practical experiments, and document my progress and useful resources on GitHub.

ToPeWe is my **independent learning initiative**. It is for technologies, emerging fields, industry knowledge, and additional technical skills—not topics from my college syllabus.

Each topic has its own documentation collection and independent numbering, so its notes and progress can grow separately. GitHub helps me keep those learning materials, experiments, and resources organized and shareable.
